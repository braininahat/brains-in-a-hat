# atlas

A Claude Code **mod** that keeps a map of the work beside the transcript, so long sessions keep their way back to the top-level plan.

- **Plan tree with a focus path.** Steps can grow sub-steps and detours; finishing one rolls up to its parent. The band above the prompt shows the breadcrumb (`▶ 3 Training › 3.2 Learning-rate sweep`), pinned facts and parked items.
- **Watchdog.** After every turn a small model (Haiku) files the turn into the tree and refreshes a recap (where we are, what was learned, what is next). When work drifts, the band offers **Return**, **Keep going** and **Park**. `/atlas recap` runs a deeper recap on Sonnet.
- **Keeper.** A background Sonnet agent (`atlas:keeper`, hidden from the main model) does the upkeep nobody should have to ask for: it renders missing pipeline-stage samples from real data into `.claude/atlas/samples/`, checks pinned facts against the repository, and fills the glossary. It starts on its own when there is upkeep to do, at most every ten minutes, and writes only inside `.claude/atlas/`. Renders shown with iris id `stage-<name>` link to their stage automatically.
- **Pane** (`/atlas`): a route picture of the plan, Now and Recap cards, the plan tree, parked tangents, facts, pipeline stages with iris thumbnails (marked *Seen* once Claude has read the render), glossary and trail.
- **Cold start.** In a project with history, `/atlas init` (or **Build map** in the band) digests every past transcript of the project (`scripts/digest.py`: what was said plus one line per tool call, in dated chunks), hands each chunk to an `atlas:historian` agent (Sonnet, read-only) in parallel, and has the session's Claude build the map from those summaries, the project's memory notes, the conversation and the repository. Contradictions become trail notes starting "Open question:". Expect a few dollars for a project with weeks of history.
- **One map per project, many sessions.** Every session in the project shares `.claude/atlas/map.json`; each change re-reads the file and merges, and each session picks up the others' changes within a few seconds. Writes take a lock (`scripts/maplock.py`; test: `scripts/maplock.test.sh`, 20 parallel writers) and replace the file in one rename, so no change is lost and no session reads half a file. Each session keeps its own place in the plan, and the Map tab shows a Sessions card with where the others are.
- Each project's map lives in that project's repo, as `.claude/atlas/map.json` plus a readable `map.md`, so it travels with `git clone` and reads the same on any machine. Commit it like any file (check your `.gitignore` does not exclude `.claude/`). `/atlas project <path>` shows another project's map.

**Needs:** Claude Code ≥ 2.1.287, the iris mod, ImageMagick for the route picture.
